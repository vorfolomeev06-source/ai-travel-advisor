# ✈️ AI Travel Advisor

An AI-powered travel assistant that helps users plan personalized trips through a simple chat interface.

Built as part of my AI Engineering studies at Ironhack.

## What it does

- Asks about your destination, dates, budget, and interests.
- Creates personalized day-by-day travel itineraries.
- Suggests approximate budgets and practical travel tips.
- Remembers previous messages and summarizes long conversations.
- Includes basic prompt injection protection and error handling.

## Tech Stack

Python · OpenAI API · FastAPI · HTML · CSS · JavaScript · Vercel

## Try it live

🌍 https://ai-travel-advisor-ten.vercel.app

## How it works

The user sends a message through the website. FastAPI processes the request, OpenAI generates a response, and the chatbot continues the conversation using its history.
